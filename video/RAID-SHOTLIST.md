# Leadership Raid — Footage Shot List

Timings are taken verbatim from the step tables in `js/specops.js` (`INFIL` + `BRANCHES`).
`t` is milliseconds from launch; the column here is seconds. **Window** is the gap until the
next beat fires — that is the longest a clip for that beat can run before the next line
overwrites the feed.

The branch is chosen *before* the first line plays (`pickBranch`), so all four timelines are
fixed and repeatable. Nothing the player does mid-mission changes them.

Look direction is night, monochrome, sensor-framed throughout — the card is a scope, not a
film. Everything should read as IR/thermal or low-light NVG with visible grain, not as
color cinema.

## Wiring notes (read before cutting)

These are constraints in the existing code, not suggestions:

1. **`overlayScopeClip` force-ends every clip at 9000 ms** (`js/map.js:1236`, stall safety).
   Nothing above needs to exceed 6s, so keep every raid clip **≤ 6s** and this never bites.
2. **One clip at a time per card.** `overlayScopeClip` bails if `.scope-hit-video` already
   exists in the wrap (`js/map.js:1218`). Back-to-back beats need the previous clip removed
   first, or the second beat silently plays nothing.
3. **Skip must cut footage instantly.** The raid card has a `SKIP ▸` button
   (`js/map.js:1673`) and `finish(true)` clears timers but not video elements — any clip
   layer added to the raid has to hook the same teardown, the way `setFastForward` drains
   `clipEnders` (`js/map.js:1258`).
4. **The clip layer sits over the SVG scope, not instead of it.** The fx calls
   (`fastrope`, `breach`, `jackpot`, `heloDown`, `teamHit`, `teamCaptured`, `exfil`) drive
   compound geometry that the feed lines reference. Footage should overlay, fade, and hand
   the frame back.
5. **Audio already fires on three beats** — `launch` at 0s, `impact` at each JACKPOT,
   `aircraftLost` on every helo loss. Source clips **without** committed audio, or they will
   fight the existing cues.
